# Governor Framework

A framework-agnostic AI agent governance system for controlling tool usage, enforcing policies, and managing compliance across different CLI environments.

## Features

- **Rule-Based Governance**: Declarative YAML rules for tool and file access control
- **State Machine Compliance**: Phase-based compliance tracking and enforcement
- **Multi-CLI Support**: Works with Devin CLI, Claude CLI, and other AI agent CLIs
- **Hook-Based Architecture**: Pre/post tool use interception and validation
- **Audit Trail**: Comprehensive logging of all governance decisions
- **Bypass Mechanism**: Configurable bypass functionality for authorized overrides

## Status

Currently in development. This is being extracted from SovereignAI to become a standalone, reusable framework.
